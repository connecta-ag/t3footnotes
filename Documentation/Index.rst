===================
Editorial footnotes
===================

:Extension key: t3footnotes
:Composer package: connecta-ag/t3footnotes
:Author: `Connecta AG <https://www.connecta.ag/>`__
:License: GPL-2.0-or-later

Editorial footnotes adds a CKEditor 5 dialog for writing notes in rich text.
The frontend renders numbered references and return links. The notes are
stored in the page cache with the rest of the rendered page.
