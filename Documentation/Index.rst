===================
Editorial footnotes
===================

:Extension key: t3footnotes
:Composer package: connecta-ag/t3footnotes
:Author: `Connecta AG <https://www.connecta.ag/>`__
:License: GPL-2.0-or-later

Editorial footnotes adds numbered footnotes to the TYPO3 rich text editor
(RTE, CKEditor 5). Editors write each note in a dialog. The frontend renders
numbered references and return links. The notes are stored in the page cache
with the rest of the rendered page.
