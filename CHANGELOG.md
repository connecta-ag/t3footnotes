## 2.0.0

### Breaking changes from 1.4.0

- Requires TYPO3 14.3 and PHP 8.4 or later. Release metadata comes from `composer.json`.
- Projects that required `cag/t3footnotes` from GitHub must change that requirement to `connecta-ag/t3footnotes`. The `connecta-ag/t3footnotes` site set and `@connecta-ag/t3footnotes/` editor module prefix are new in 2.0 under the new name. The extension key and PHP namespace stay the same.
- Replace the CKEditor 4 integration and its toolbar item with the supplied CKEditor 5 preset import and the `t3footnote` button.
- Enable the `connecta-ag/t3footnotes` site set. Remove the Extbase list plugin records, the former TypoScript include and Fluid template overrides. Use site settings or a placement marker instead.
- Rendering moves to TYPO3's cache-generation event. Notes generated by USER_INT or COA_INT and standalone error handlers are outside that event.
- Update CSS for `.t3footnote-ref`, `.t3footnotes` and the backlink role. The page list keeps the usual `fn-anchor-N` and `fn-content-N` fragment IDs when available. Local lists use their own prefixes.
- Existing 1.x notes keep the `sup.t3foonote` storage contract.

### Editor and rendering

- Inline widgets and a note dialog based on Rémy Daniel's CKEditor 5 work, with English, German and French editor translations. [Community PR #11](https://github.com/connecta-ag/t3footnotes/pull/11)
- A note appears as a raised marker that keeps its line height, with hover, selected and focus states in the light and dark backend scheme.
- One click selects a note and shows its text with Edit and Delete buttons. A double click or Enter opens the dialog.
- The dialog is wider, places the label above a field that grows with the note, explains the numbering, keeps Delete apart from Cancel and Save, and saves with Ctrl+Enter or Cmd+Enter.
- The renderer preserves the page source around edited ranges, supports page and local lists, and exposes one event for changing note content.

### Upstream requests

- [Issue #3](https://github.com/connecta-ag/t3footnotes/issues/3), AllowedContent side effect. TYPO3's normal content filtering stays enabled.
- [Issue #5](https://github.com/connecta-ag/t3footnotes/issues/5) and [PR #6](https://github.com/connecta-ag/t3footnotes/pull/6), stale version. Composer metadata replaces `ext_emconf.php`. CI checks release tags against the declared version.
- [Issue #7](https://github.com/connecta-ag/t3footnotes/issues/7), footnotes with HTML. Safe legacy inline HTML renders and HTTP(S) URLs can be auto-linked. New notes use plain text. Bold, italic and links in the dialog are planned for 2.1.
- [PR #8](https://github.com/connecta-ag/t3footnotes/pull/8), sites without setup. Sites without the extension site set leave their HTML unchanged.
- [PR #9](https://github.com/connecta-ag/t3footnotes/pull/9) and [PR #10](https://github.com/connecta-ag/t3footnotes/pull/10), earlier TYPO3 compatibility. Superseded for 2.0. Stored content is kept through upgrades via TYPO3 11–13. The 2.0 renderer runs on TYPO3 14.3.
- [PR #11](https://github.com/connecta-ag/t3footnotes/pull/11), CKEditor 5. Rémy Daniel's widget and dialog are the basis of the 2.0 editor.
