# Security policy

## Supported versions

Security fixes go into the latest 2.x release.

## Report a vulnerability

Please do not open a public issue. Report the vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/connecta-ag/t3footnotes/security/advisories/new)
on this repository. If you cannot use GitHub, write to
[kontakt@connecta.ag](mailto:kontakt@connecta.ag).

Include the affected version, the TYPO3 and PHP versions and the steps to
reproduce the issue.
